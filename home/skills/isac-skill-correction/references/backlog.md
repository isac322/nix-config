# Backlog: 아직 배치하지 않은 사용자 요구

증류 작업(2026-09-26)에서 확인했지만 어느 스킬에도 넣지 않은 사용자 요구다. 스킬을 새로 만들거나 기존 스킬에 넣을 때 이 목록에서 꺼내 근거를 다시 확인한다. 근거는 `세션 8자 msg id`(ask 답변은 `ASK@시각`)다. 배치하면 해당 항목을 지우고 옮긴 스킬과 규칙 ID를 커밋 메시지에 적는다.

## 1. release 스킬 (프로젝트 사실)

- CRD 안내는 신규 설치와 업그레이드를 구분한다. Helm chart는 OCI 레지스트리와 GitHub Release에 게시하고, multi-arch 빌드는 릴리스에서만 하며 지원 아키텍처는 베이스 이미지를 따른다. 근거 01a0c7e8 39610c51, 4e04b39d; 01a095f6 c8dd5251, 0b86cd32.

## 2. IaC / Terraform 워크플로

- 인프라와 자격증명(저장소 설정, environment secret, branch protection 포함)을 코드로 관리하고 기존 리소스는 import한다. 저장소의 기존 IaC 레이어 관계까지 맞춘다(사용자 교정 포함). 근거 01a095f6 76e79bca, 012e9868, 00ebedad, 582c9d0b.
- 배포·시크릿 동기화는 현재 클러스터가 이미 쓰는 방식을 재사용한다. 근거 01a095f6 02194318.
- plan/apply 전에 중단 조건을 정하고, drift가 있으면 전체 apply 대신 범위를 좁힌다. 사용자가 알려 준 provider 노이즈는 승인 후 진행한다. 근거 01a095f6 efc2065b.
- "무관한 drift"라고 주장할 때는 구체적으로 명명하고 다시 검증한다. 근거 01a095f6 ASK@2026-09-16T13:36.
- plan 결과는 최신 artifact로 확인하고 stale 데이터로 결론 내리지 않는다(사용자 교정). 근거 01a095f6 c4219d73.
- 시크릿이 필요한 apply의 실행 주체와 권한 문서화는 `isac-decision-brief`가 이미 소유한다. 근거 01a095f6 ASK@2026-09-15T12:13.

## 3. 새 저장소 기본값

- CI 전부 green, Dependabot을 저장소가 쓰는 모든 생태계에 대해 매일 KST 09:00, 최소 크기 이미지(scratch, non-root, static stripped), 최신 언어 버전 기준 컨테이너 인식 런타임 설정. 근거 01a095f6 aefe9972.
- CI는 실제 의존성 해석 경로를 거친다(빌드한 패키지를 자체 metadata로 설치, lock 주입 금지). 사용자가 허용한 나머지 격차는 과설계하지 않는다. 근거 01a0d288 e94992d7, a3e962d3.

## 4. 최신 버전 정책

- 의존성, 도구, 언어, API는 결정 시점의 최신 버전을 쓰고 그 값을 pin한다. 문서와 스킬은 버전 값을 복사하지 않고 pin 위치를 참조한다. 근거 01a095f6 ff776f79.

## 5. 저장소 지식 영속화

- "그 설명이 저장소에 남아 있어?"라는 질문에는 실제 docs, README, Makefile, workflow, 주석을 확인하고, 문서화된 것과 도구 동작에서 추론한 것을 구분해 답한다. 누락분은 운영 문서(언제·왜)와 메커니즘 설명 문서로 나눠 남긴다. 근거 01a095f6 b88d9d23, 4c1e7e2a.
- 대화에서 합의한 컨벤션과 세션 암묵지를 저장소 하네스에 남기는 방향은 `isac-skill-correction` SKC-11(저장소 자체 지침)로 라우팅만 정해져 있고, 추출 절차 자체는 스킬이 없다. 근거 01a095f6 5c6cdfcf.
