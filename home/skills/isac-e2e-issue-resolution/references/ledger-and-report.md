# 진행 ledger와 최종 보고 (E2I-13, E2I-18, E2I-19가 읽는다)

바꿀 수 있는 기본값이다. 저장소 밖 scratch 위치에 둔다. 공개 게시물에 복사하지 않는다.

## ledger

머리(run 단위, E2I-01):

```text
repo: <owner>/<repo>  default: <branch>  mode: publish|draft
targets: <#N, … | all open>  merge: none | <#N, …> (지시 요지 한 줄)
started: <시각>
```

이슈마다 한 행:

| 필드 | 내용 |
|---|---|
| issue | `#N` 제목 요지 |
| owner | 담당 서브에이전트 id |
| stage | `중복정리` / `트리아지` / `수정` / `리뷰` / `머지` / `종결알림` 또는 종착 이름(`references/state-machine.md`) |
| verdict | 재현 결과와 판정 어휘(`issue-validation`), 라벨 |
| root cause | 한 줄, 합의 여부 |
| pr | 번호, 리뷰한 head SHA, CI, 리뷰 판정(`GREEN`/`BLOCKING`, `PR-ready`) |
| posted | 게시한 댓글·PR·리뷰 URL(GHP-11 추적) |
| waiting | 기다리는 것: 사용자 결정, 제보자 정보, 외부 요인 |
| reason | 종착이면 근거 한 줄 |

기록 시점: 단계가 바뀔 때, 게시할 때, 사용자 결정이 들어올 때. 완료 선언 전에 이슈 목록을 다시 조회해 ledger와 대조한다(TRI-02).

## 최종 보고 형식(한국어)

결론 한 줄로 시작한다: 대상 N건 중 머지·종결 a, PR 대기 b, 정보·재현 대기 c, 승인 대기 d, 기타 e.

1. **이슈별 종착 표**

   | 이슈 | 종착 | 근거 한 줄 | PR·머지 커밋 | 게시물 |
   |---|---|---|---|---|

   대상 전부를 한 줄씩 넣는다. 중복은 정본 번호를 근거에 적는다.
2. **게시한 것**: 댓글·PR·리뷰·라벨 URL. 초안 모드면 "게시 가능" 한 줄과 초안 위치.
3. **남은 것**: 열린 PR(머지 미승인), 정보·재현 대기, 외부 블로커와 필요한 접근, "merged but unreleased" 목록(E2I-15), run 중에 새로 드러난 결함(E2I-02 재조회 결과).
4. **사용자 결정 필요**: 구조 변경 브리프(`isac-decision-brief` 형식, 이슈별), 머지 승인 요청(전역 머지 가드의 최종 세부), 종결 권고. 결정이 없으면 "없음".
5. **검증**: 실행해서 확인한 것과 확인하지 못한 것을 나눈다. 제보자 동등 환경 검증을 못 한 이슈는 그 한계를 적는다(I2P-52).
6. 실행 중 사용자가 이 스킬을 교정했다면 `isac-skill-correction` 안내 한 줄.

각 이슈 설명은 사용자가 바로 이해할 수 있게 짧게 쓴다: 무엇이 문제였고 어떻게 해결했는지(또는 왜 멈췄는지).

## 중간 보고(E2I-19)

같은 종착 표를 현재 stage로 채운다. 남은 이슈는 TRI-34 형식(문제, 해결 가능 여부, 추가 정보 필요 여부)을 붙인다.
