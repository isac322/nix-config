# Slack message completeness

- When the user points to a Slack message or thread, or a task requires reading, answering, or acting on Slack messages, read each relevant message in full, including its attachments.
- Attachments include images, screenshots, files, snippets, link unfurls, and Block Kit content. Download every image or screenshot through the authorized Slack credential and view it, and read every attached file or snippet.
- An empty or short message `text` does not mean the message has no content. Inspect `files`, `attachments`, and `blocks` before concluding what a message says.
- Do not reply to, summarize, or act on a message until its attachments have been read. If an attachment cannot be retrieved, say so explicitly instead of answering from the text alone.
