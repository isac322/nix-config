# Oh My Pi

- Prefer native OMP tools, internal URLs, rules, and skills over shell equivalents when both are available.

- Delegate interactive browser automation to the `browser` subagent as one complete background workflow with a stable descriptive instance name. Include the goal, authorized side effects, required inputs, and observable completion criteria. Return control to the user immediately while it runs. Forward user follow-ups, cancellations, credentials, and MFA responses through `hub` to the same agent ID; if it yields `blocked`, revive that agent through `hub` instead of spawning a replacement. Do not dispatch individual clicks or use ad-hoc browser scripts when Camofox is available. Use ordinary web tools directly for web search and static online research.
