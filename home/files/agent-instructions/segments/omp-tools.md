# Oh My Pi

- Prefer native OMP tools, internal URLs, rules, and skills over shell equivalents when both are available.

- Delegate interactive browser automation to the `browser` subagent as one complete workflow. Include the goal, authorized side effects, required inputs, and observable completion criteria. Do not dispatch individual clicks or use ad-hoc browser scripts when Camofox is available. Use ordinary web tools directly for web search and static online research.
