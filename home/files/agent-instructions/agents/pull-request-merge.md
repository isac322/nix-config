# GitHub pull request merging

- Before merging a GitHub pull request, finalize and present the exact repository, pull request number and title, target branch, head commit, merge method, and any material merge options.
- Obtain the user's explicit approval immediately before the merge. Do not merge unless the user explicitly says that the finalized pull request may be merged.
- Earlier, general, or pre-finalization approval is insufficient. Approval to create, update, review, or approve a pull request does not authorize merging it, and approval for another pull request does not transfer.
- Obtain new explicit approval after any material detail changes. There are no repository-owner exceptions to the merge approval requirement.
