# Pull request creation

1. Determine the base repository and its owner, not the head repository owner.
2. Prepare the final base branch, head branch, title, body, reviewers, and assignees.
3. If the base repository owner is `runbear-io`, include `runbear-bot` as a reviewer and assign `isac322`.
4. If the base repository owner is neither `runbear-io` nor `isac322`, present the finalized details and obtain the user's explicit approval immediately before creation. Earlier, general, pre-finalization, or different-action approval is insufficient.
5. If the base repository owner is `runbear-io` or `isac322`, creation does not require approval.
6. If any material creation detail changes after approval, present the new finalized details and obtain new explicit approval.
7. Create the pull request only with the finalized arguments after the applicable approval and metadata requirements are satisfied.
