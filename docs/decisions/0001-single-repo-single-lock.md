# 0001. 기기 전부를 한 레포에

**결정** — 기기마다 레포를 나누지 않고 단일 flake 에 담는다.

레포를 하나로 두는 이유는 `flake.lock` 이다. lock 하나가 nixpkgs 리비전부터
home-manager, llm-agents 까지 전부 고정한다. 기기별로 레포를 나누면 lock 도 나뉘고,
맥북의 vim 과 서버의 vim 이 서로 다른 버전으로 갈라진다. "대부분의 설정을 공유"라는
전제가 거기서 깨진다.

대가는 lock 이 공유 상태가 된다는 것이다. `switch` 는 lock 을 건드리지 않지만
`nix flake update` 는 다시 쓰므로, 갱신은 한 기기에서만 하고 나머지는 pull 한다 —
[운영 · 기기 간 독립성](../operations.md#기기-간-독립성).

빌드까지 공유되는 것은 아니다. 각 기기는 자기 설정을 스스로 빌드하고 전환하며,
서버는 맥에 전혀 의존하지 않는다.
